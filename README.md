# Sahaya (सहया) — Offline AI Field Assistant for ASHA Workers

> **Empowering frontline healthcare workers with offline intelligence, household prioritization, and hands-free voice assistance.**

---

## 📌 Overview

In rural India, **Accredited Social Health Activists (ASHAs)** deliver critical healthcare services across thousands of communities—tracking childhood immunizations, identifying high-risk pregnancies, and facilitating government maternal benefit schemes. However, field visits are frequently hampered by **unreliable cellular connectivity**, dense paper registers, and complex clinical guidelines.

**Sahaya** is an **offline-first AI field companion** designed specifically for frontline workers. Operating 100% on-device with zero cloud dependencies, Sahaya turns complex clinical protocols into actionable, prioritized household visits and grounded spoken answers.

---

## ✨ Key Capabilities

- 🎯 **Intelligent Household Prioritization**  
  Uses a deterministic scoring engine that cross-references SQLite records with the official **Universal Immunization Programme (UIP)** schedule and maternal health thresholds. Households are automatically triaged into **`CRITICAL`**, **`ATTENTION`**, and **`ON TRACK`** tiers based on overdue vaccine doses, clinical danger signs (e.g., severe anemia $\text{Hb} < 7.0$, blood pressure $\ge 140/90$), and visit staleness.

- 🎙️ **Hands-Free Multi-Turn Voice Assistant**  
  Built for real-world field conditions where workers need one-handed operation while interacting with families. Retains a multi-turn conversation buffer (last 1–2 turns) so natural follow-up queries (e.g., *"Aarav ko agla vaccine kab lagna hai?"* $\rightarrow$ *"aur agle mahine?"*) resolve accurately without repeating context.

- 📄 **100% Grounded Protocol Q&A (Zero Hallucination)**  
  Every answer generated by the assistant is strictly retrieved from verified government health guidelines, complete with official citations (**MoHFW**, **NHM**, **PMSMA**, **PMMVY**, **JSY**).

- 🌐 **Multilingual Regional Support**  
  Localized UI chrome and on-device speech-to-text / text-to-speech support across:
  - **Hindi (`हिन्दी`)**
  - **Tamil (`தமிழ்`)**
  - **Marathi (`मराठी`)**
  - **English**

- 📱 **ASHA-Centric UI (Terracotta-Blue Theme)**  
  Built in native **Jetpack Compose** following an icon-first, high-contrast visual hierarchy with large tap targets, collapsible clinical accordions, and an always-accessible voice trigger.

## 🛠️ Architecture & Stack

| Component | Technology | Description |
|---|---|---|
| **Mobile Platform** | **Native Android (Kotlin + Jetpack Compose)** | Modern declarative UI, Material 3, unbundled offline APK |
| **Local Database** | **SQLite (`001_shared_schema.sql`)** | Stores households, maternal checkups, immunization history, and priority queue |
| **Retrieval Engine** | **On-Device TF-IDF Vector Retrieval** | Computes cosine similarity over official health protocol corpora with derived confidence scores |
| **Speech Processing** | **Android SpeechRecognizer & TextToSpeech** | Offline ASR & TTS configured for regional Indian locales (`hi-IN`, `ta-IN`, `mr-IN`, `en-IN`) |
| **Reference Engine** | **Python 3.11+ Backend** | Full reference implementation of prioritization logic, retrieval tests, and HTTP loopback server |

## 🚀 Setup & Installation

### Option 1: Native Android App (`android/`)

#### Prerequisites
- **Android Studio** (Ladybug / Koala or newer recommended)
- **JDK 21** (Android Studio bundled JBR or OpenJDK 21)
- **Android SDK**: `compileSdk 35`, `minSdk 26`
- **Device / Emulator**: Android 8.0+ (Pixel 7 with API 34 recommended)

#### Building and Running via Android Studio
1. Open Android Studio and select **Open**, then browse to the `android/` directory.
2. Wait for Gradle sync to complete.
3. Connect an Android device with USB debugging enabled, or start an Android Virtual Device (AVD).
4. Click **Run ▶️** (`Shift + F10`) to build, install, and launch the app.

#### Building via Command Line (Gradle Wrapper)
```bash
cd android

# Build Debug APK
./gradlew assembleDebug

# Install directly to a connected device or emulator
./gradlew installDebug
```

---

### Option 2: Python Reference Engine & Test Suite

The Python suite serves as the reference implementation for automated testing and protocol verification.

#### Prerequisites
- **Python 3.11+**

#### Running the Automated Test Suite (16 Unit Tests)
Run the complete unit test suite validating the prioritization math, visit penalties, maternal risk scoring, and multi-turn retrieval:
```bash
python -m unittest discover -s tests -v
```

#### Running the Local Web Server
Start the lightweight loopback server for testing API endpoints (`/api/households`, `/api/ask`, `/api/prioritize/refresh`):
```bash
python app.py
```
Then navigate to `http://127.0.0.1:8080` in your web browser.

## 🔒 Offline Privacy & Safety

- **100% On-Device**: All database transactions, vector searches, and voice recognition processes run locally on the smartphone.
- **Zero Cloud Leakage**: No personally identifiable health data or visit logs are transmitted over the network.
- **Sourced Verifiability**: Recommendations cite official government scheme documents and immunization schedules to prevent generative hallucination in the field.
